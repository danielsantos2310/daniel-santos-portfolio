# Hello! Welcome to my ePortfolio.
This is my interactive ePortfolio I created using Node Js, React JS, and MongoDB.
Technologies used for this project are React Context API, Mongoose, Node Js Express server, and Fontaweseome. This project is live and deployed on Heroku.

## Node.js version

Use Node.js 22 for local development and Netlify builds. Run `nvm install` and
`nvm use` to select the version in `.nvmrc`. The Netlify configuration also pins
Node.js 22 so builds do not fall back to the site's previous Node.js 16 setting.

Before running Netlify CLI commands in an existing shell, run `nvm use` as well.
The repository's runtime settings apply to builds but do not switch the Node.js
interpreter of a shell that is already running.
